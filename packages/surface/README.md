# @trinker_vul/surface

Attack-surface discovery for [Trinker](https://github.com/Paardhu22/trinker):

- `discoverSurface` — Express and Fastify routes from TypeScript/JavaScript source, including
  cross-file router mounts, with honest confidence levels
- `ingestOpenApi` — operations from an OpenAPI document
- `ingestHar` — routes from recorded browser or proxy traffic, scoped to one origin
